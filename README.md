# Dual Design Co

Custom WordPress theme for Dual Design Co. Built with PHP, Tailwind CSS, and ACF flexible content layouts.

Developed by [Web Ok](https://webok.ca).

## Development

Install dependencies:

```bash
npm install
```

Start the dev server:

```bash
npm start
```

Build for production:

```bash
npm run build
```
